The camera sees in pixels, and the robot moves in millimetres. Calibration connects the two. First, the lens is calibrated to remove distortion. Then a camera-to-robot calibration is performed, so a position in the picture becomes an exact position in the robot's own coordinates, measured from an agreed home position. The method depends on the robot type. For a six-axis arm, the robot moves a calibration board through many poses. For other robot types, it touches a set of marked points. Camera 2's calibration is the critical one, because it tells the robot exactly where to pick the disc. The system also checks itself on a schedule against fixed reference marks. If it drifts, it recalibrates automatically once, and if it is still out of tolerance it stops and asks for maintenance.

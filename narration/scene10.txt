The system is built to handle problems safely. Unsure discs are rejected, never guessed. The sensor count is compared with the discs found, so a missed disc is noticed. Unpicked discs fall into a catch bin and return to the input. The system also watches for wear. As stamping tools or discs wear, the sides look different, so confidence and reject rates are trended and an alarm is raised early. A built-in brightness check watches the lights, and if a camera or lamp fails the cell stops or rejects instead of guessing. New disc types are added by photographing them and training that type, without redesigning the cell.
